# Glow Tap — Event kiosk edition

The same direct-touch game, now using bevelled 3D neon plus prisms, magenta X crystals and golden stars. Scoring, timing, negative targets and existing best scores are unchanged.

## Play on Windows

Run `release/Glow-Tap-Leaderboard-x64.exe`. The portable app contains Electron, Three.js, the shaders and all event assets. No Node.js installation or internet is needed. Windows 10/11 and WebGL 2 capable graphics are required. The executable is unsigned.

PLAY.bat automatically downloads a private Node.js 24 LTS runtime, verifies its checksum, installs locked dependencies and builds and starts the game. First setup needs internet; administrator access and global Node.js installation are not required. BUILD-EXE.bat rebuilds the portable executable in release/.

## Play on a Mac

Double-click PLAY.command. On first launch it downloads a private Node.js 24 LTS runtime into .runtime/ (checksum-verified, nothing installed system-wide), installs the locked dependencies including Electron, builds the game and opens it fullscreen. First setup needs internet; later launches work offline. Esc or Cmd+Ctrl+F leaves fullscreen, Cmd+Q quits.

If macOS says the file can't be opened or you lack access privileges, open Terminal and run: bash followed by a space, then drag PLAY.command into the window and press Return. Alternatively, right-click PLAY.command and choose Open once.

## Same touch rules

- Tap cyan plus objects for 10 points. Golden stars give 40.
- Skip magenta X objects. A wrong touch deducts 30 points, resets the streak and cancels Rush. Scores floor at zero; ignoring an X is safe.
- Five good hits charge six seconds of double-point Glow Rush. Negative targets remain negative during Rush.
- The round defaults to 30 seconds and does not end early after negative touches.
- Touch input is direct; different targets support simultaneous touches. Mouse clicks and optional keys 1–9 work too. P pauses, F11 toggles desktop fullscreen.
- Existing negative-target and minimal-edition high scores are retained.

## 3D graphics and shaders

- True bevelled extruded meshes, gentle 3D tilting and small orbiting light fragments.
- Custom GLSL vertex displacement and animated colour-flow, scan-line, moving-highlight and Fresnel-rim material shading.
- Cinematic bloom and an explicit colour-management output pass. Shape and colour families stay distinct for readable decisions.
- Additive shader shockwaves and glowing 3D shard bursts on touch.
- Intro previews render the exact same meshes and shaders as the game; they are not static images.
- The main renderer draws the animated backdrop; the second renderer draws 3D previews only while visible. Pixel ratio is limited to control GPU cost. Reduced-motion settings freeze animated materials and drift and suppress particle bursts.

## Sound and first play

The first screen uses a large 5K logo, Enter your name, and Let’s play, with a Ready. Set. Glow. hero and floating 3D neon accents rendered into the main scene to avoid rectangular canvas edges. Touching the field opens the built-in touch keyboard; a physical keyboard also works. Let’s play opens the catch / bonus / skip instructions, where Let’s play is immediately enabled. Optional target previews never affect the score. The timer starts after the countdown.

An original, locally synthesized 116 BPM soundtrack uses pads, bass, plucks and drums. The warm-up has a softer mix; Rush adds rhythmic energy. Distinct sounds mark catches, gold bonuses, wrong touches, Rush, countdown and results. Music and SFX have independent saved controls. Audio starts on the first player interaction and music pauses when the game is paused or hidden.

A custom aurora shader adds flowing cyan / violet ribbons, drifting stars, gentle beat response and touch ripples behind the playfield. Reduced-motion preferences freeze the background motion.

Music and sound are generated by src/game-audio.js; no third-party recordings or streaming services are used. Background shading is in src/aurora-background.js.

## Round duration

Edit game-config.json next to the portable EXE, for example { "gameTimeSeconds": 30 }. Valid values are whole seconds from 5 to 3600. The app creates the file with a 30-second default if absent. It reads the JSON at launch and again when the player presses Let’s play on the entry screen, so changes apply to the next round without rebuilding. PLAY.bat uses the game-config.json in the source project root. Browser development uses public/game-config.json. Invalid JSON or an out-of-range value falls back to 30 seconds.

## Event player data and leaderboard

Every completed round saves the player name, score, ISO timestamp and unique round ID to Documents/Glow Tap/players.csv. Documents is the current Windows account’s actual Documents folder, including OneDrive redirection. The app also maintains players.json there as its persistent leaderboard data; retain it alongside the CSV. Existing rounds survive app restarts. Ties keep the earlier round first; the leaderboard shows at most ten names. A player outside the top ten occupies a highlighted bottom slot with their actual rank for five seconds alongside the top nine; then the real top ten are restored. Players within the top ten are highlighted in place. After 10 seconds without touch, mouse movement, keyboard or scroll input, entry, instructions and running or paused rounds return to a blank name-entry screen. The leaderboard instead has a fixed 15-second deadline unaffected by input, plus a Start new game button that returns to the same blank entry screen. The on-screen keyboard, unfinished round and temporary effects are cleared; saved leaderboard sessions and historical CSV data remain intact. The results countdown reflects the fixed 15-second deadline. No replay prompt is shown.

Ctrl+R starts a fresh leaderboard session and returns to entry. It does not reload the app or delete previous player records. Historical players.json and players.csv remain intact; later CSV exports contain all sessions, identified by the Leaderboard session column. The current session ID persists in Documents/Glow Tap/leaderboard-session.json, so restarting keeps the new board.

CSV output uses UTF-8 with a BOM for Excel and quotes values safely. Close players.csv in Excel while running the event so the game can update it. A save failure is shown on the leaderboard, with a local browser-storage copy retained. No personal data leaves the laptop.

The Windows executable and PLAY.bat save CSV automatically. Browser development mode retains scores locally and offers Save CSV on the leaderboard because browsers cannot silently write to Documents. No sample players are shipped in the source or executable.

## Development

npm ci; npm test; npm run dev; npm run build; npm run build:exe.

Game rules: src/tap-state.js. Touch, score UI and audio: src/minimal-main.js. Geometry, shaders, postprocessing and 3D previews: src/neon-visuals.js. Layout: src/minimal.css.

All shaders and assets are local, with no CDN dependencies. Event logo provenance is documented in BRAND-SOURCES.md. External camera or LiDAR tracking is not included.
